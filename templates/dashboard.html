📖 About LexCloud

LexCloud is an AI-powered platform that analyzes legal documents using the Google Gemini API. Upload contracts, NDAs, and employment agreements to get instant insights about risks, parties, and key dates.

✓ AI-powered Document Analysis
  • Automatically extracts parties, dates, risks
  • Identifies high-risk clauses
  • Categorizes contract types
✓ Multi-format Support
  • PDF and DOCX files
  • Secure S3 storage
  • Real-time processing via Lambda
✓ Risk Assessment
  • Low/Medium/High risk levels
  • Detailed risk explanations
  • Historical tracking
✓ Analytics Dashboard
  • Monitor all documents
  • Track processing trends
  • View contract statistics
How to Get Started
  1. Sign up and log in
  2. Go to the "Upload" tab
  3. Select a PDF or DOCX file
  4. Click "Analyze" to run AI analysis
  5. View insights and risk assessment
Technology Stack
  • AWS: Elastic Beanstalk, Lambda, S3, DynamoDB, CloudWatch
  • AI: Google Gemini 3.6 Flash
  • Backend: Flask (Python)
